# MathorCup 2024 · C 题 物流网络货量预测与人员排班

2024 年 MathorCup 数学应用挑战赛 C 题参赛论文，队号 MC2403042，获省级三等奖。

## 题目

给 57 个分拣中心的历史货量，预测未来 30 天每个中心每天、每小时的货量；
再按预测结果排班：60 名正式工 + 若干临时工，一天分 6 个班次，正式工每天最多一个班次、
出勤率不高于 0.85，临时工连续出勤不超过 7 天，目标是总人数和效率偏差都尽量小。

## 方法

- **货量预测**：ARIMA。先用箱线图查异常值、拉格朗日插值补空值，再按 ADF 定差分阶数 d，
  用 AIC 选 p、q，逐中心建模预测未来 30 天。小时级预测用附件给的每小时占比缩放。
- **网络修正**：把分拣中心当节点、线路当边，算节点强度和主要流通道，修正第一问的日预测。
- **排班**：线性规划。决策变量是正式工/临时工各班次人数和效率偏差，
  约束为工作量不低于预测货量、人员非负、正式工每日一班等，目标是最小化人数与偏差。
- **问题四**：在问题三基础上加出勤率 ≤0.85、连续出勤 ≤7 天（工 5 休 1，出勤率 0.83）的约束。
